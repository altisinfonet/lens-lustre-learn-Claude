  ⚠ INSTRUMENT DEFECT, FOUND AND FIXED BEFORE THIS EVIDENCE WAS KEPT.
  The first scan matched `.rpc(` and the quoted name with a pattern whose
  cast form was `\(\s*[\w$.]*\.rpc\s+as\s+[^)]*\)` — the `[^)]*` cannot span
  the nested parentheses in

      (supabase.rpc as unknown as (
         name: string, args: Record<string, unknown>
       ) => PostgrestBuilder
      )("create_system_post", { … })

  so it silently missed BOTH real call sites of create_system_post
  (src/lib/profilePostHelper.ts:41, src/pages/MyPhotos.tsx:409). The
  re-written scan is shape-independent: it finds every occurrence of the
  QUOTED name and looks back 300 characters for `.rpc` in any form. Same
  defect class as C-A8 and C-A10. It did not change the grouping —
  create_system_post is in 0035 either way — but a caller census that misses
  a call site is how a revoke becomes an outage, so it is recorded.
