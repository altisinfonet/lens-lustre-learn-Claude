## 1. HOW THIS REPO WORKS — the things that waste an hour if you do not know

* **No `git push`.** The proxy returns 403. Every commit goes through the GitHub
  web **Upload files** UI, one directory at a time, then **byte-verify**:
  `git show origin/main:<path> | cmp -s - <path>`. Do not skip the verify — two
  commits silently failed to land today and were caught only by that check.
* **After uploading, the commit summary field is the FIRST box.** Clicking the
  second box puts your message in the description and the commit is titled
  "Add files via upload". Screenshot before clicking Commit.
* **Migrations do NOT auto-apply.** SQL files under `supabase/migrations/` are a
  record. Real changes are typed into the **Supabase SQL editor** by hand.
  Type **one statement per line, balanced brackets and quotes per line** — the
  Monaco editor auto-closes brackets and will corrupt multi-line statements.
* **Edge functions do NOT auto-deploy** either. Hand-deploy in the dashboard.
* **Cloudflare Pages builds with `bun install --frozen-lockfile`.**
  `package.json` and `bun.lock` MUST be committed together or every deploy dies.
* **The app bundles `dist` locally** (`webDir:'dist'`, no `server.url`). Web
  fixes are invisible in the app until a build is cut and installed.
* **The sandbox cannot reach `cdn.50mmretina.com` or `50mmretina.com`** — its own
  egress allowlist, NOT Cloudflare blocking you. `supabase.co` and `github.com`
  work. To test the live site, drive the owner's browser (Claude in Chrome) and
  measure inside the page with `javascript_tool`.
* **The lint baseline `scripts/audits/baselines/as-any-protected-baseline.json`
  is keyed on `file:line`.** Adding an import shifts every `as any` below it and
  turns CI red. Shift those entries by the same amount; do not regenerate.
