## Why this transcript is discriminating and not merely "a failure"

§15.2 N1 requires refusal **by the ref-assertion gate**, before any SQL executes. A run that merely
fails proves nothing. Four independent properties establish that this is the right refusal:

1. **Steps 2 and 3 PASSED.** The branch check and the credential-present check both succeeded, so the
   failure cannot be attributed to a wrong branch or a missing secret. Only the lane check fired.
2. **The error string matches the gate's source exactly** — `.github/workflows/apply-migration.yml`,
   step *"The credential must point at the target database"*, emits precisely this text.
3. **`Run it` is recorded as skipped.** This is the half most transcripts omit, and it is the half that
   proves no database was touched.
4. **Job duration 7s.** `Install psql` alone takes appreciably longer; the timing corroborates that the
   run stopped before the psql path.

**The gate refused WITHOUT CONNECTING, as §8.1 states it must.**
