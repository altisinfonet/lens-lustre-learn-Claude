## ✅ CLOSED 2026-08-10

### The app's blank pages — ROOT CAUSE FOUND AND FIXED
> *"after changing pages sometimes coming and sometime showing blank pages"*

Found in **our own production log**, not by reasoning — Admin → Site Health →
Client failures, build 1058, `platform = app`:

```
Blank page / crash   7×   TypeError · crypto.randomUUID is not a function
sys                 13×   A route crashed; the member is on the Reload screen.
```

`crypto.randomUUID` needs Chromium 92+ and a secure context; an Android System
WebView that has never been updated has neither, and it updates through the Play
Store independently of the OS. Fourteen bare call sites — including the device
id (every start-up) and the nav menu seed (every page) — threw, reached
`AppErrorBoundary`, and left a header with nothing under it. Different pages
touch different call sites, which is exactly why it looked random.

Fixed with `safeRandomUUID()` + a repo-wide gate that fails CI on any direct
call. **Full write-up: `claude/ROOT_FIX_BLANK_PAGE_RANDOMUUID.md`.**
