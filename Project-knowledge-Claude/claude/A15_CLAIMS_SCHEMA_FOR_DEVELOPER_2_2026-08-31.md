## 4. `risk`, and the rule that keeps it honest

`risk` is **a routing hint about where a reviewer should spend time, with a stated basis** — never a
finding, never "this file is fine". In Developer 2's half my generator assigns `test` → `LOW` and the
three `web *` categories → `LOW`, **on the stated basis that none of them is on an auth, privacy or
serialisation boundary.** That basis is exactly what the review should test, so **if you raise a row
above `LOW`, state the basis you are overriding.**
