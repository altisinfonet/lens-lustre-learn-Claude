## H. Added 2026-08-12

18. **Android has none of the Top Contributors or Active Engagement work.**
    `capacitor.config.ts` uses `webDir: 'dist'` with no `server.url`, so the APK ships a
    bundled copy of the web build from build time. App users see no score badge, no Home
    score, and record **zero** engagement. **Needs an AAB.** Until then the Android
    background/battery behaviour of the collector is unverified on a device.

19. **Video lessons are the collector's biggest blind spot.** `LessonView.tsx` embeds video in
    a cross-origin `<iframe>`. Clicks inside the player never fire the page's input events, so
    a member watching a 20-minute lesson attentively earns **about 2 minutes**. The collector
    cannot tell playing from paused. Reported only — needs a decision, not a patch.

20. **Post categories — audit done, nothing built, 6 decisions waiting.** See
    `AUDIT_POST_CATEGORIES_2026-08-11.md`. Two traps to carry: (a) a minimum-1-category rule
    would break three existing `posts` insert paths that have no human choosing categories —
    album auto-post, profile-update post, and the scheduled-posts cron; (b) the stored
    interest string is `Astrophotography` while the new list says `Astro`, so renaming is a
    silent data migration, not a label change.

21. **Phase 2b and 2c must NOT start automatically.** The Active Engagement collector is
    running. The owner will request an *Active Engagement Data Quality Report* after real
    collection time, and that report decides whether the 120s rule and the 20% weighting are
    approved at all.
